I've unsubscribed from all repositories on GitHub and unfollowed all open source organizations.

I'll occasionally check in on pending issues and pull requests, but I don't plan to address non-critical issues on any particular timeframe.
If you need my attention, please email me using the address on my GitHub profile.

## Individual Projects

I've moved my personal projects that have active co-maintainers into those users or organizations on GitHub.
Remaining projects will continue to triage security reports per [Tidelift's requirements](https://support.tidelift.com/hc/en-us/articles/4406288074260-Lifter-tasks-overview).
They all have a security policy that asks reporters to responsibility disclose issues over email.

### [create-typescript-app](https://github.com/JoshuaKGoldberg/create-typescript-app) (and [Bingo](https://create.bingo))

CTA and the underlying framework, Bingo, are pretty much stable.
I'll try to bring CTA up to date with the latest common practices a few times a year.
I have no major changes planned for either.

### [Flint](https://flint.fyi)

I still believe in the project, but am ~~leaving it in the hands of the team~~ not going to be active every day.
More like every week
As I have spare cycles I'll hope to try to make progress - especially now that TypeScript 7.1 has stable APIs coming.
And the team knows they can always `@` me for input if they want.

> Edit: I overstated how much I was willing to step back from this beloved project.

### [Mocha](https://mochajs.org)

Mocha has another maintainer, Mark, who is still active.
I'll continue to work on pushing [Mocha 12](https://mochajs.org/blog/mocha-12-rc-1) out the door as well as continuing our [community sponsorships](https://mochajs.org/blog/2026-community-sponsorships "Mocha community sponsorships").
Given how non-cutting-edge Mocha is now, I expect we'll continue to slowly strengthen Mocha's feature freeze over time.

### [typescript-eslint](https://typescript-eslint.io)

I plan to continue chipping in a few times a month on issue triage and pull request review (mostly the latter).
The project is fairly sedentary given ESLint's architectural constraints, so other than using TypeScript 7's new APIs I don't know of any major changes planned.

---

I'm proud of what I've been able to build and contribute to in open source, and I'm grateful to everyone who has helped maintain these projects along the way.
Thanks to all the wonderful people in open source who've made the journey fun.

For now, though, I'm going to go touch grass.
